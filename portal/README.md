# CHUNIL Smart Mail Portal — 팀 공용 통합 포털 서버

천일정기화물자동차(주) **납입1팀 전원**이 **GitHub 가입·Secrets 등록·코드 복붙 없이**
주소 하나로 접속해 **자기 회사 웹메일 아이디/비밀번호**만 넣으면 쓰는 통합 대시보드입니다.

```
팀원 PC·휴대폰 ──(사내망)──▶  이 서버 1대 (server.py)
                                  │  ├─ mail.chunil.co.kr 로그인 검증 (본인 계정)
                                  │  ├─ 본인 메일만 수집·분석 (10분마다)
                                  │  └─ data/users/<아이디>/board.json  ← 본인만 열람
```

- **팀원이 하는 일**: `http://<서버PC IP>:8080` 접속 → 웹메일 ID/PW 입력 → 끝.
- **처음 로그인한 사람**: 최근 14일 메일(최대 30건)을 자동 수집·분석해 보드를 만들어 줍니다(1~3분, 그동안 진행률 표시).
- **운영자(과장님)가 하는 일**: 이 서버 한 대만 켜 두면 됩니다. 화면·수집 로직을 고치면 **접속한 전원이 새로고침만으로** 새 화면을 씁니다.
- **자동 업데이트(v1.2.0~)**: 서버가 5분마다 GitHub의 `mail-board-template/portal` 을 확인해 바뀐 파일만 스스로 받습니다. 화면은 재시작 없이 F5, 코드는 문법 검사를 통과하면 새 프로세스로 조용히 갈아탑니다.
- **가볍게(v1.2.1~)**: 9,000건이 넘는 보드도 ① gzip 압축(11MB → 1.2MB) ② 압축본 재사용 ③ 내용이 그대로면 **304(0바이트)** 로 내려갑니다. 화면도 5분 자동 점검에서 바뀐 게 없으면 다시 그리지 않아, 다른 자리에서 로그인해도 끊기지 않습니다.
- **직급 자동 인식(v1.2.1~)**: 사내 조직도의 '직위' 칸이 비어 있어도 보낸/받은 메일의 서명·호칭에서 직급을 읽어 **`김성규 과장`** 처럼 표시합니다.
- **유사도 한눈에(v1.2.2~)**: `✨ AI 정밀 분석` 결과마다 **`92% 유사`** 큰 배지와 게이지 바로 원문 대비 유사도를 보여 줍니다. 85% 이상 **매우 유사**(초록) · 65~84% **관련 높음**(파랑) · 65% 미만 **참고**(주황).
- **목록은 언제나 최신 수신순(v1.2.3~)**: 모든 탭에서 받은 시각 순으로 위가 최신입니다. 등급(1-1·1-2·1-3)은 같은 시각일 때만 순서를 가릅니다.
- **AI 분석 실패는 이유까지(v1.2.3~)**: 요청 한도·API 키·응답 지연을 구분해 안내하고, 응답이 길어 잘리지 않도록 토큰을 늘렸습니다(코드펜스로 감싼 JSON 도 읽습니다).
- **로고·슬로건은 본문이 아니다(v1.2.4~)**: 서명에 따라붙는 회사 로고·CI·슬로건 배너·SNS 아이콘(12KB 미만)은 본문 사진에서 빼고, 본문 하단의 회사 슬로건(`Hi CHUNIL, High green`·`The Next 100`)과 기밀 면책 문구도 AI 분석 전에 걷어냅니다. **직원 서명(이름·직급·연락처)**과 사진·표·본문은 그대로 둡니다.
- **v1.2.23 — 발신자 칩은 한 사람에 하나, 설명 띠는 닫는다**: ① `🟡 흐름 참고` 등 탭의 발신자 필터 칩이 `변요환 대리 8` + `변요환 1`, `강한 사원 5` + `강한 1` 처럼 **직급 표기 차이로 같은 사람이 두 칸으로 갈리던 문제** — 이름에서 직급(부장·차장·과장·대리·사원·팀장…)을 떼어 낸 값 하나로 묶고, 발신자 칸이 메일 주소뿐인 메일은 주소록 이름으로 붙여 **한 사람 = 한 칩**으로 합칩니다(`변요환 대리 19`, `강한 사원 342`). 표시명은 직급이 붙은 표기로 통일하고, 상사 건처럼 그 묶음이 과반 등급 라벨이면 지금처럼 `1-2 주요` 같은 중립 등급명을 그대로 씁니다. 칩을 누르면 그 사람의 모든 표기 메일이 함께 걸립니다. ② 칩이 3줄로 늘어 목록을 밀어내지 않게 **처음엔 8개(좁은 화면 4개)만** 보여주고 나머지는 **`+ N명 더보기 ▾`** 로 접어 두며 **`접기 ▴`** 로 되돌립니다(지금 고른 발신자는 접힌 쪽에 있어도 함께 보입니다). ③ 탭 설명 띠(`흐름 참고`·`기록 보관`·`📌 고정`·`⏳ 미회신 추적`) 오른쪽 끝 **`✕`** — 한 번 닫으면 모든 탭에서 사라지고 새로고침·탭 전환 뒤에도 유지됩니다(`mb_guide_hide_v1`). 탭 줄 끝의 작은 **`?`** 로 다시 켭니다. ④ `📅 내 캘린더` 아래 **범례 줄**(`■ 내가 등록한 메일 ■ 긴급 ■ 오늘`)을 없앴습니다 — 실제 달력 색과 맞지 않던 줄입니다.
- **v1.2.24 — 왼쪽 사옥 배너가 10분마다 일출 ↔ 야경으로 바뀐다**: 넓은 PC 화면 왼쪽의 본사 사옥 배너에 **야경(별이 쏟아지는 밤) 사진**을 한 장 더 넣고, 두 사진을 겹쳐 둔 채 **10분마다 2.2초 동안 스르륵 크로스페이드**로 바뀝니다. `The Next 100` · `70년의 경험에 혁신을 더하다` · `CHUNIL CARGO TRANSPORTATION` 글씨는 사진 위에 그대로 얹혀 있어 **전환 중에도 위치가 흔들리지 않고**, 팝업·알림은 없으며 토큰도 쓰지 않습니다(화면 모션만). 새로고침하면 다시 일출부터 시작하고, `움직임 줄이기(prefers-reduced-motion)` 설정에서는 흐림 없이 즉시 바뀝니다. 야경 사진(`assets/left-banner-night.jpg`)도 자동 업데이트 대상에 넣어 팀원 PC 에도 5분 안에 내려갑니다.
- **v1.2.25 — 무료 Gemini 한도에 안 걸리게, 팀원 메일은 ‘회신 완료’로 덮지 않는다**: ① 무료 등급 Gemini API 의 분당 한도(`429`)에 걸리지 않도록 **분석 호출 사이에 기본 4초**를 두고(테스트는 0초), `429` 를 받으면 `Retry-After` 를 존중하거나 **15 → 30 → 45초**로 늘려 버팁니다(5xx 는 짧게). ② 그래도 **일일 한도(RPD) 소진**이면 45초씩 기다리지 않고 **`gemini-3.5-flash-lite`(무료 500건/일 · 3.8-flash 는 20건/일) → `gemini-3.1-flash-lite`** 로 **자동 우회**해 그 동기화를 끝까지 성공시킵니다(다음 주기는 다시 `gemini-3.8-flash` 로 시작). ③ 신규 메일은 **🔴 즉시(1-1·1-2·1-3)를 🟡 흐름 참고보다 먼저** 분석해, 한도가 빠듯한 날에도 중요 메일이 먼저 AI 분석을 받습니다. ④ 한도·네트워크로 분석이 빠진 메일은 **`aiPending`** 으로 남겨 다음 주기마다 최근 5건씩 자동 재분석해 채웁니다(수동 `✨ AI 다시 분석` 성공 시에도 해제). ⑤ **우리 부서 팀원이 보낸 메일이라도 수신(To)이 나이거나 본문에서 나를 지목했으면** `[회신·송부 완료 · 추가 회신 없음]` 으로 덮지 않고 **내가 확인·조치할 건**으로 판정합니다(팀원이 외부·타팀에 회신한 건은 그대로 회신 완료). ⑥ 왼쪽 사옥 배너의 일출 ↔ 야경 전환을 **10분 → 3분**으로 줄였습니다.
- **v1.2.26 — 왼쪽 사옥 배너가 1분마다 일출 ↔ 야경으로 바뀐다**: `#10163` 요청대로 전환 주기를 **3분 → 1분(60,000ms)** 으로 줄였습니다. 두 사진을 겹쳐 두고 1분마다 2.2초 크로스페이드로 바꾸는 방식과 글씨 위치는 그대로이고, 팝업·알림·토큰 소비는 없습니다(화면 모션만). 새로고침하면 다시 일출부터 시작합니다.
- **v1.2.27 — 사옥 배너가 흐려지면서 부드럽게 바뀐다(블러+페이드 · 30초)**: `#10263` “걍 띡 바뀌네” 수정 — ① 원인은 두 가지였습니다. (a) 일출·야경 두 레이어가 **동시에** 투명해지는 구조라 중간 프레임에서 뒤의 어두운 배경색이 비쳐 전환이 끊겨 보였고, (b) OS의 **`움직임 줄이기`(prefers-reduced-motion)** 설정이 켜진 PC에서는 `transition:none` 이 적용돼 **아예 즉시** 바뀌었습니다. ② 이제 아래 일출 레이어는 늘 불투명하게 두고 위 야경 레이어만 `opacity` + `filter:blur(10px→0)` 로 **2.6초** 동안 올리고 내립니다 — 앞 사진이 흐려지며 사라지고 뒷 사진이 흐린 상태에서 선명해지며 나타납니다. ③ `움직임 줄이기` 설정에서도 전환을 끄지 않습니다(끄면 오히려 더 튐). ④ 전환 주기는 `#10275` 요청대로 **1분 → 30초(30,000ms)**. 글씨 위치·팝업·알림·토큰 소비는 그대로입니다.
- **v1.2.28 — 원문 웹메일은 보기만 해서는 '읽음'이 되지 않는다(확인했을 때만 읽음)**: `#10347` → `#10483` "확인 처리 한 거만 읽음 처리 되어야겠지" — ① 수집이 본문을 읽으려고 편지읽기 화면(`mail_read.php`)을 열면 웹메일이 그 메일을 '읽음'으로 바꿔 버려, 보드만 봐도 원문이 읽힌 것처럼 남던 문제를 없앴습니다. **목록에서 '안 읽음'이던 메일만** 본문·첨부를 읽은 직후 `mail_mark.php`(POST `cmf[]`)로 **곧바로 '안 읽음'으로 되돌립니다** — 이미 '읽음'이던 메일은 건드리지 않습니다. ② 이제 보드에서 **상세를 열어 보기만 하면 원문은 '안 읽음' 그대로**이고, 행·상세의 **`✓ 확인`(일괄 확인 포함)을 눌렀을 때만** 원문 웹메일이 '읽음'이 됩니다(`POST /api/mail/mark-read`, 저장된 웹메일 세션 재사용·중복 호출 방지·실패해도 화면은 그대로). ③ 항목마다 원문 상태(`unread`)를 함께 저장하고, `✨ AI 다시 분석`·사진 첨부 보정처럼 본문을 다시 읽는 경로도 읽은 뒤 되돌려 원문 상태를 덮지 않습니다. ④ 포털 서버·각자 GitHub Actions 수집 모두 같은 규칙입니다(정적 Pages 는 서버가 없어 화면에서 아무 것도 보내지 않습니다).
- **v1.2.5 — 실사용 다듬기**: ① 로그인 세션이 서버 재시작·PC 재부팅 뒤에도 유지(`data/sessions.json`, 0600) ② 본문 속 `제출 기한 : 12월 2일`·`마감 : 12/2`·`~ 12/2 까지` 를 직접 읽어 캘린더 기본 날짜로 ③ `📅 등록한 메일` 카드에도 `📅 옮기기`(날짜 선택 폼) ④ 캘린더 날짜를 누르면 그 날 **등록·마감 메일**이 아래 목록에 모임 ⑤ 본문 낱말이 `<span>11</span>월` → `11\n월` 로 찢기던 문제(수집·화면 양쪽) ⑥ **이미 저장된** 슬로건 배너·엑셀 아이콘 사진 자동 정리(기동 시 + 동기화 시 + 화면 안전장치) ⑦ 첨부파일 제목 옆 `웹메일 원문에서 받기 ↗`(v1.2.17 에서는 하단 `웹메일 원본 ↗` 한 곳으로 통일).

## 1. 서버 PC 에서 딱 3단계

**준비물**: Windows 10/11 PC 1대(계속 켜 둘 PC), Python 3.10 이상, 사내망·인터넷, 회사 웹메일 계정.

### ① 폴더 복사
이 폴더(`mail-board-server`)를 서버로 쓸 PC 의 `C:\mail-board-server` 같은 곳에 그대로 복사합니다.

### ② `start_portal.bat` 더블클릭
- 처음 실행하면 필요한 라이브러리(`requests`, `beautifulsoup4`, `cryptography`)를 자동 설치합니다(1~2분).
- `.env` 가 없으면 **GEMINI_API_KEY 를 한 번** 물어봅니다. 모르면 그냥 Enter — 요약은 기본 규칙 모드로도 동작하고, 나중에 `.env` 에 한 줄 추가하면 켜집니다.
- 방화벽 규칙(8080)을 자동 등록하려 시도합니다(관리자 권한이 없으면 건너뜀 — 아래 ③ 참고).

### ③ 화면에 뜬 주소를 팀원에게 알려주기
검은 창에 이렇게 뜹니다.

```
  이 PC에서 열기      : http://127.0.0.1:8080
  팀원에게 알려줄 주소:
      http://192.168.0.12:8080       ← 이 주소를 단톡방에 공유
```

> 팀원 PC에서 안 열리면 **방화벽**입니다. 서버 PC에서 **관리자 권한** 명령 프롬프트를 열고 한 번만:
> ```
> netsh advfirewall firewall add rule name="CHUNIL Portal 8080" dir=in action=allow protocol=TCP localport=8080
> ```
> IP 확인: 서버 PC에서 `ipconfig` → `IPv4 주소` (예: 192.168.0.12).
> **검은 창을 닫으면 서버가 꺼집니다.** 끄지 말고 최소화해 두세요.

**계속 켜 두기 팁**
- Windows 설정 → 시스템 → 전원 → 절전 모드 해제(화면 꺼짐 허용).
- 재부팅 후 자동 시작: `시작 프로그램` 폴더(`Win+R` → `shell:startup`)에 `start_portal.bat` 바로가기를 넣어 두면 됩니다.
- PC가 꺼지면 팀원 전체가 접속할 수 없습니다(보드는 남아 있어 다시 켜면 그대로).

### 검은 창 없이 켜기 (권장)

- **`start_hidden.vbs` 더블클릭** — 검은 창 없이 뒤에서 서버가 돌아갑니다(`pythonw.exe`). 실수로 창을 닫아 서버가 꺼지는 일이 없고, 화면에는 6초짜리 안내만 뜹니다. 이미 8080에서 돌고 있으면 중복 실행하지 않고 주소만 알려 줍니다.
- 로그는 `data\server.log` 에 남습니다(5MB 넘으면 `server.log.1` 로 넘김). 문제가 생기면 이 파일을 보세요.
- **끄기**: `stop_portal.bat` 더블클릭(8080을 쓰는 파이썬 프로세스만 종료). 다른 포트면 `stop_portal.bat 8081`.
- **재부팅 자동 시작**: `Win+R` → `shell:startup` → 열린 폴더에 `start_hidden.vbs` **바로가기**를 넣어 두면 PC를 켤 때마다 조용히 서버가 올라옵니다.
- 처음 한 번은 라이브러리 설치를 위해 `start_portal.bat`(창 있는 실행)을 한 번 돌려 두세요.

## 2. 팀원 사용법 (가입·설치 없음)

1. 브라우저에서 `http://192.168.0.12:8080` 접속(휴대폰은 사내 Wi-Fi).

5. 휴대폰은 브라우저 메뉴 → `홈 화면에 추가` 로 앱처럼 고정해 쓰면 편합니다.

## 3. 개인정보·보안 (중요)

- **메일은 서버 안에만** 있습니다. `data/users/<아이디>/board.json` 은 그 사용자의 세션 쿠키로만 내려가고, 다른 사람이 URL 로 접근할 수 없습니다(서버가 파일 경로도 막습니다).
- **웹메일 비밀번호**는 `data/.server_key`(자동 생성, 소유자만 읽기 `0600`)로 **AES-256-GCM 암호화**해 `data/users/<아이디>/cred.enc` 에 둡니다. 10분 자동 갱신에만 쓰고, 로그·화면·응답에는 절대 나오지 않습니다.
- **조직도는 공용, 개인주소록은 개인**입니다. 공용 파일에는 조직도(`kind=org`)만 들어가고, 개인주소록은 각 사용자 폴더에만 저장됩니다.
- **`data` 폴더는 절대 공유·백업 업로드 금지**(개인 메일·비밀번호 암호문·주소록이 들어 있습니다). 서버를 옮길 때는 `data` 폴더째 복사하세요.
- 이 서버는 **사내망(LAN) 사용을 전제**로 한 HTTP 서버입니다. **공인 인터넷에 그대로 열지 마세요.** 외부(집·휴대폰 LTE)에서도 써야 한다면 HTTPS·VPN·리버스 프록시가 필요합니다.
- 서버를 재시작하면 로그인 세션이 풀립니다(보드는 그대로, 다시 로그인만). 퇴사자·기기 분실 시 해당 사용자의 `data/users/<아이디>` 폴더를 지우고 서버를 재시작하세요.

## 5. 중앙 업데이트 (자동 — 서버가 스스로 받아 옵니다)

배포본은 GitHub `seongkuy0427-blip/mail-board-template` 의 **`portal/` 폴더 하나**입니다.
서버는 시작 20초 뒤부터 **5분마다** 그 폴더의 `manifest.json`(작은 JSON)만 받아 내 파일의
sha256 과 비교하고, **달라진 파일만** 내려받습니다.

| 바뀐 것 | 서버가 하는 일 | 팀원이 느끼는 것 |
| --- | --- | --- |
| `index.html` (화면) | 임시 파일로 받아 교체(`os.replace`) — 재시작 없음 | 다음 접속·**F5** 만 하면 새 화면 |
| `server.py` · `scripts/*.py` (로직) | 임시 파일 → `py_compile` 문법 검사 → 통과한 것만 교체 → **새 프로세스로 자동 재시작** | 몇 초 사이 재접속(로그인 세션은 다시) |
| 네트워크·GitHub 장애 | 경고 로그만 남기고 다음 주기(5분)에 재시도 | 아무 일도 없음(서버는 계속 돔) |
| 깨진 파일(문법 오류·변조) | **교체 거부**, 기존 파일 보존 | 그대로 정상 동작 |

- `data/`(메일·비밀번호 암호문) · `.env`(설정) 는 **절대 건드리지 않습니다**. 되돌리기 어려운 일은 하지 않습니다.
- 현재 버전·업데이트 상태는 `http://127.0.0.1:8080/api/health` 와 시작 검은 창(또는 `data\server.log`)에서 확인합니다.
- 확인만 해 보고 싶으면: `python server.py --check-update` (내려받지 않고 JSON 으로 차이만 보여 줌).
- 잠시 끄려면: `.env` 에 `PORTAL_AUTO_UPDATE=0` (한 번만 끄려면 `--no-update`).

**운영자가 새 버전을 내보내는 방법** (개발 PC에서)

```bash
python make_manifest.py --copy-to ../template-build/portal   # 배포 파일 복사 + manifest.json 생성
cd ../template-build && git add portal && git commit -m "portal v1.3.0" && git push
```

올린 뒤 5분 안에 팀 전체 서버가 알아서 따라옵니다. 손으로 SHA 를 적을 일은 없습니다.

> `index.html` 은 `mail-board-template`(GitHub) 의 화면에 **포털 모드 패치**(`PORTAL`, `LSK`, `/api/*`)가 들어간 파일입니다. 템플릿 화면을 새로 받아 덮어쓸 때는 포털 패치 부분을 다시 합쳐 `portal/index.html` 로 올려야 합니다(그 파일이 자동 배포본입니다). `scripts/sync_mail.py` 는 무수정 그대로 씁니다.

## 8. 자체 검증 (개발·수정 후)

가짜 웹메일/가짜 Gemini 로 서버 전체를 실제 HTTP 로 돌려 봅니다(인터넷·계정 불필요).

```bash
python test_server.py -v
python3 check_ui.py            # index.html 스크립트 문법 + 가짜 DOM 실행
python3 check_rules_list.py    # ⚙️ 설정 목록 60건 + 더 보기
python3 check_case_ai.py       # 🔗 유사 사례 · ✨ AI 정밀 분석 렌더
python3 check_ui.py            # 📝 메일 분석 3단 · [✨ AI 요약 실행] 렌더도 함께 점검
```

검증 항목: 로그인 성공/실패 · 사용자 간 데이터 격리 · 최초 로그인 백그라운드 수집과 진행률 · `/api/state` 저장·복원 ·
조직도 공용/개인주소록 격리 · `cred.enc` 암호화 라운드트립 · 정적 화면·포털 플래그 · 로그아웃 · Gemini 경로 · 수동 새로고침 반영 ·
**과거 메일 백필(배치 병합·이미 기록 있는 보드 건너뜀)** · **`/api/similar` 캐시 히트** ·
**자동 업데이트(manifest sha256 비교 → index.html 무재시작 교체 · 손상된 .py 교체 거부)** ·
**메일 분석 3단(진행 경과·주담당·결론) · 스레드 증분 캐시 · ⚪ 기록 보관 Zero-Token · `POST /api/mail/analyze` 온디맨드 분석**.

`check_*.py` 는 `quickjs` 가 필요합니다(`pip install quickjs`). 없으면 test_server.py 만 돌려도 됩니다.
